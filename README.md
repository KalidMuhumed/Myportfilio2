# Kalid Muhumed — Portfolio

Personal portfolio skeleton for **Kalid Muhumed** — fullstack developer & automation. Built with Next.js App Router, TypeScript, Tailwind CSS, and Lucide Icons.

## Design

- **Background:** Obsidian Black `#141413`
- **Cards:** Subtle Graphite `#1E1E1C`
- **Headings:** Cream White `#FBFBF9`
- **Body:** Warm Muted Slate `#A39E93`
- **Accent:** Terracotta Orange `#D97757`
- **Typography:** Playfair Display (serif headings) + Geist (sans body/nav)

## What’s included

- Sticky navbar with logo, section links, and GitHub / LinkedIn / email icons
- Mobile menu (lightweight, no heavy frames)
- Centered hero with portrait fade, name, role line, and “Kontakta mig” CTA

## Run locally

```bash
npm install
npm run dev -- --port 43127 --hostname 0.0.0.0
```

Open [http://127.0.0.1:43127](http://127.0.0.1:43127).

| Command | Description |
| --- | --- |
